# Buzdolabı Lambası Karanlık Tutanağı

Resmi adı: **TentiAŞ Ulusal Soğuk Zincir Aydınlatma ve Kapı Kapanınca Ne Olur Komisyonu**

Gayriresmi adı: lamba söndü, yoğurt konuştu.

Bu depo, buzdolabı kapısı kapanınca lambanın söndüğü iddiasını kabul etmez. Lamba sönmez. Lamba **tutanak tutar**. Siz görmezsiniz. Yoğurt görür. Yoğurt konuşmaz. Komisyon konuşur.

Patates yoktur. Asansör yoktur. Dolmuş yoktur. Varsa da bu dosyada değildir, yanlış rafa konmuştur, zabıt tutulmuştur.

## Ne işe yarar

Hiçbir işe yaramaz. Buna rağmen çalışır. Bu ülkenin en dürüst cümlesidir.

`python3 lamba_tutanak.py` çalıştırıldığında komisyon:

1. Kapının kapandığını tespit eder.
2. Lambayı görevden almaz, karanlık raportör ilan eder.
3. Raftaki her gıdayı tanık olarak dinler.
4. Tek kalmış çorabı (buzdolabında ne işi varsa) muhalefet şerhi sayar.
5. 7 maddelik karar basar. Karar her seferinde aynıdır: **lamba haklıdır, kapı şüphelidir.**

## Kurulum

```bash
git clone https://github.com/Tentivory/buzdolabi-lambasi-karanlik-tutanagi
cd buzdolabi-lambasi-karanlik-tutanagi
python3 lamba_tutanak.py
```

Bağımlılık: Python 3. Ve karanlıktan korkmayan bir terminal.

## Bilimsel yöntem

Kapı açıkken deney yapılamaz, çünkü lamba herkesi görür ve utanır. Kapı kapalıyken deney yapılamaz, çünkü siz göremezsiniz. Dolayısıyla tek geçerli yöntem tutanaktır. Tutanak bilimdir. Bilim soğuktur. Soğuk, buzdolabıdır. Döngü kapanmıştır. Kapı da kapanmıştır.
